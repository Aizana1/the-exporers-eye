Drop object photos in this folder. The game loads them automatically.

Each file must be a .jpg named exactly after its object id:

  Americas
    potlatch-mask.jpg      Potlatch Transformation Mask (E_Am1944-02-146)
    americas-second.jpg    Northwest Coast Carving (E_Am1990-08-2)

  China
    dragon-tiles.jpg       Fahua Glazed Dragon Tiles (A_2006-0503-1-1-20)
    china-second.jpg       Chinese Ceramic Work (A_1957-0501-1)

  Egypt
    younger-memnon.jpg     The Younger Memnon (Y_EA19)
    egypt-second.jpg       Egyptian Sculpture (Y_EA24)

  Africa
    ife-head.jpg           Cast of an Ife Crowned Head (E_CRS-12)
    africa-second.jpg      African Artwork (E_Af1979-01-2397)

Tips
- If a file is missing, the game shows the object's emoji instead (no broken image).
- To use .png instead of .jpg, update the matching "image:" path in data.js.
- Square images look best (they are shown in a square frame, cropped to fill).
- File names are case-sensitive and use hyphens, exactly as above.
